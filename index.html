📒 对账单生成器

只需填好 日期、名称、数量、单价，自动生成对账单：货款明细（按月小计/年度总计）+ 付款流水 + 退货记录 + 总账，一键导出 Excel。

📖 使用说明（点开看）
1. 先填好顶部的「甲方 / 乙方 / 期初余额」；
2. 在「货款明细」里逐行填写，或点「批量粘贴」从 Excel/微信一次性贴入多行（每行：日期 名称 数量 单价 单位 发货单号 备注，Tab 或逗号分隔）；
3. 「金额 = 数量 × 单价」自动计算，按月份自动出小计、按年份出总计；
4. 付款、退货同样录入；「总账」页自动汇总余额；
5. 点底部「导出 Excel」生成 .xlsx 文件，可直接发微信；「打印」可打印全部表单。
多客户：顶部可「＋新建客户」切换账目（甲方默认「许道丰」，各客户互不影响）；
数据自动保存在本浏览器中，下次打开还在（清浏览器缓存会丢失，重要数据请导出 Excel 备份）。
👥 当前客户（乙方） 新建客户时甲方默认「许道丰」；各客户账目互相独立，切换互不影响。
数量/单价任意一项留空则该行不计入小计；备注可写「余量16付」「要配脚」等说明。
付款流水：日期 + 付款金额（备注选填）。余额列会自动累计。
退货记录：日期 + 名称 + 数量 + 单价，金额自动计算，底部自动出「退货共计」。

公式：期末余额 = 期初余额 + 累计总货款 − 总付款 − 总退货（累计总货款 = 各期货款合计，不含期初；应收余额 = 期初余额 + 累计总货款）
